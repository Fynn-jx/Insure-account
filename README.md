# 保险会计学 · 复习图谱

保留课件原有的 **8 章、32 节**，以整章思维导图串联知识。前三章根据 6 页手写导图识别、校对并补全，知识点可回查课件 PDF，手写稿原图保留在本地。

## 功能

- 思维导图：缩放、拖动、折叠、章节定位、全文搜索、重点标记与 SVG 导出。
- 挖空复习：基础 10 空、进阶 20 空、强化 25 空，点击词库填入，检查答案、查看答案和重练错题。题量以当前范围可考内容为限。
- 难度梯度：进阶、强化包含同章干扰项，词条可以重复选；强化须填完再统一检查。首次成绩与订正结果分开记录。
- 个人编辑：修改节点说明、增加子节点、自定挖空词、撤销及 JSON 备份；保留原有章、节结构。
- 离线阅读：双击 `打开复习系统.html` 可直接使用，保留 `sources/` 等配套目录即可回查资料。

个人内容、标记和练习进度保存在当前浏览器中。换域名、浏览器或设备时，个人内容可从“我的编辑”导出 JSON，再在新地址导入；练习进度分别保存。

## 本地运行

无需安装依赖。在项目目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/`。也可以直接打开离线入口。

## 测试与构建

需要 Node.js 22 或更高版本，无第三方运行依赖。

```sh
npm test
npm run build
```

构建只将应用、课件 PDF、导出导图和使用资料复制到 `public/`，不会发布构建脚本、原始 OCR 或本地配置。

## 部署到 Vercel

导入 GitHub 仓库 `Fynn-jx/Insure-account`，使用仓库根目录、Framework 选择 **Other**，保留仓库内的 `vercel.json` 设置：

| 配置 | 值 |
| --- | --- |
| Install Command | 空，不需要安装依赖 |
| Build Command | `node scripts/build-static.cjs` |
| Output Directory | `public` |

网站使用静态文件与 `#chapter1` 等章节锚点，不需要数据库或环境变量。Git 集成完成后，推送到生产分支可自动更新部署。

## 内容维护

- `build_data.py`：课件知识点与小节内容。
- `build_chapters.py`：保留原章节层级，补充手写稿校对内容。
- `data/slides-source.json`：课件提取文字，供回查与重建使用。
- 手写 OCR 原始输出留在本地，仅供校对，不上传仓库。
- `sources/课件整合版.pdf`：课件转换 PDF；手写稿图片保留在本地，不上传。

编辑内容源后运行 `python3 rebuild.py`，重建课程数据、整章 SVG、资源指纹与离线页面，然后运行测试及静态构建。原始大体积 PDF、PPTX 和本地中间文件保留在项目外。

课程中的数字、政策和案例沿用课件语境。公式、表格、分录和案例条件请结合原课件核对。
